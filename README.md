# 挎包里的津沽

天津农商银行金融文化遗产网页游戏，用三代人的身份体验串联“遗产、记忆、视界”。

## 运行

直接打开 `index.html` 即可。为避免浏览器对本地文件下载功能的限制，也可以在当前目录启动任意静态服务器。

## 当前功能

- 全屏开场与三代身份地图
- 生产队会计、乡镇个体户、返乡创业者三套独立关卡
- 每代包含“寻找时代线索、做出生活选择、装入精神原则”三项任务
- 三枚信用印记与完整通关状态
- 1952、2005、2010、2025历史档案库
- 独立 WAV 音轨循环播放的舒缓纯音乐，无旁白、无人声，并保留轻量交互音效
- “稳健传承—创新变革”未来结局生成器
- 可下载的个人结局海报
- 桌面端、平板与手机端响应式布局

## 内容原则

页面中的官方历史节点、合成叙事和未来推演已分别标注。正式参赛前，应继续补充经授权的老照片、口述史原声、实物扫描和完整参考文献，并进行最终史实复核。

## 文件

- `index.html`：页面内容与语义结构
- `game.css`：游戏视觉、响应式和动效
- `game.js`：场景绘制、三代关卡、声音与结局逻辑
- `assets/津沽舒缓纯音乐.wav`：48 秒可循环播放的原创舒缓纯音乐
- `styles.css`、`app.js`：上一版展览网站的源文件备份
